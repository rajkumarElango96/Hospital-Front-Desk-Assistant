COMPONENT RUNS ON PORT NOTES
Nginx EC2 · systemd 80 / 443 Serves React static files, proxies /api/* to Fastify
Fastify API EC2 · PM2 4000 (internal) Core API — spawns MCP server on startup, never exposed publicly
MCP Server EC2 · child_process stdio only Owns Prisma, runs 5 tools, communicates via JSON-RPC 2.0 newline-delimited
PostgreSQL EC2 · systemd 5432 (internal) Not exposed publicly. 6 models, unique constraint prevents double-booking
OpenAI GPT-4o External SaaS 443 Full tool-calling loop. All turns sent with complete conversation history
Vapi.ai External SaaS 443 + PSTN Outbound voice call + tool webhook POSTs to EC2's /api/voice/tool
Gmail SMTP External SaaS 587 (TLS) Nodemailer. Requires SMTP_USER + SMTP_PASS (Gmail App Password) in .env
